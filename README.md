# 上海精智实业股份有限公司 · 新版官网

参考 Google、SpaceX 等国际头部公司网站风格打造的深空工业风官网，自适应手机与电脑。

## 使用方式

双击 `index.html` 即可在浏览器中打开（无需服务器）。

如需本地预览服务器（视频等资源加载更接近线上环境）：

```bash
cd 官网
python -m http.server 8730
# 浏览器访问 http://127.0.0.1:8730
```

## 文件结构

```
官网/
├── index.html          # 页面主体（单页 + 锚点导航）
└── assets/
    ├── css/style.css   # 全部样式（深空主题 · 响应式）
    ├── js/main.js      # 交互脚本（星空、滚动显现、Tab、视频等）
    ├── img/            # 优化后的图片素材（logo / 工厂 / 产品长图）
    └── video/          # 执行监控演示视频（20s）
```

## 设计要点

- **配色**：深空藏蓝底 `#04070D` + 精智红 `#E60013` + 蓝沃青 `#2FD3DF`，金属渐变标题
- **首屏**：Canvas 星空粒子 + 流星 + 发光网格，品牌使命大标题 + 数据滚动
- **区块**：关于精智（价值观 / 发展历程 / 工厂版图横滑）→ 六大业务板块 → 工业AI·蓝沃（三大智能体 + 演示视频）→ 制造能力 Tab → 行业与匿名案例 → 资质荣誉（认证 + 荣誉跑马灯）→ 新闻动态 → 联系我们 → 页脚
- **动效**：滚动显现、计数动画、卡片悬浮光效、跑马灯、滚动进度条
- **数字人 · 小智**：进入主页 2.5s 后弹出欢迎弹窗（打字机问候，同一会话只弹一次）；悬浮按钮可随时唤出对话面板——内置公司知识库问答、快捷问题、跳转引导与语音播报（Web TTS，默认关）
- **兼容**：无 JS 也可正常显示内容；`prefers-reduced-motion` 自动降级

## 调试参数

- URL 加 `?noloader`：跳过加载动画（截图 / 自动化测试用）

## 内容口径说明

全部文案基于《展示资料包_公开资料增强脱敏版_20260917》及公开网站信息整理：
- 客户案例均为**匿名**表述，不出现客户名称与具体收益数字
- 线体图片为渲染示意，不表述为项目验收记录
- 资质荣誉区分「历史获评」与「当前有效」，按材料标注年度
